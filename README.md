# 🔥 Fire Insight 2.0

### 소방청 공공데이터 기반 산업시설 화재 발생 특성 및 피해 심각도 분석

## 1. 프로젝트 개요

Fire Insight 2.0은 소방청 화재 데이터를 활용하여 산업시설 화재의 발생 특성, 발화요인, 재산피해 및 인명피해를 분석하는 데이터 분석 프로젝트입니다.

기존 산업시설 화재 분석 프로젝트를 고도화하여 **데이터 품질 진단, 전처리, 탐색적 데이터 분석(EDA), 통계적 검정, 대시보드 시각화**까지 하나의 분석 파이프라인으로 구현했습니다.

**프로젝트 핵심 목표:** 데이터 전처리의 재현성과 검증 가능성을 확보하고, 화재 피해의 주요 특성을 정량적으로 설명하는 것

## 3. 데이터 개요

- 데이터 출처: 소방청 화재 데이터
- 전체 화재 데이터: 123,299건
- 산업시설 화재 데이터: 24,678건
- 원본 컬럼: 19개
- 전처리 후 컬럼: 27개

## 4. 데이터 전처리

주요 전처리 작업은 다음과 같습니다.

- 산업시설 화재 데이터 추출
- 조사서번호 중복 검사 및 문자열 변환
- 컬럼별 결측률과 자료형 분석
- 재산피해액 숫자형 검증 및 로그 변환
- 건물층수 결측 여부 표시
- 발화층 데이터 범주화
- 건물구조 표준화 및 유사 표기 정리
- Parquet 형식의 분석용 데이터 생성

### 건물구조 표준화

원본 건물구조 분류 24개를 분석용 21개 범주로 정리했습니다.

`기타`, `기타 조`, `기타(건물구조조코드)`를 `기타/미분류`로 통합하고, `블럭조`를 `블록조`로 정규화했습니다.

원본 값은 보존하며, 통합 범주는 분석용 분류입니다.

## 5. 데이터 전처리 검증

| 검증 지표 | 결과 |
|---|---|
| 전처리 전 데이터 | 24,678건 |
| 전처리 후 데이터 | 24,678건 |
| 데이터 보존율 | 100% |
| 조사서번호 중복 | 0건 |
| 자동 검증 | 7개 항목 통과 |
| 건물구조 범주 | 24개 → 21개 |

데이터 보존율은 행 손실 여부를 나타내며, 모든 데이터 값의 정확성을 보증하는 지표는 아닙니다.

## 6. 주요 분석 결과

### 6.1 발화요인별 화재 발생

산업시설 화재에서 전기적 요인이 8,395건으로 가장 많았으며, 부주의 7,059건, 기계적 요인 3,653건 순으로 나타났습니다.

### 6.2 재산피해 집중도

재산피해 상위 약 1%의 화재 사건이 전체 재산피해액의 약 67.38%를 차지했습니다.

일부 대형 화재가 평균 피해액에 큰 영향을 미치므로 중앙값과 분위수를 함께 비교했습니다.

### 6.3 건물구조별 피해 심각도

발생 건수 100건 이상인 건물구조 중 철골조의 대형 피해 발생 비율은 15.27%로 나타났습니다.

이는 발생한 화재 중 고액 피해 사건의 비율이며, 건물구조 자체의 화재 발생 위험률을 의미하지 않습니다.

## 7. 통계적 검정

- 카이제곱 검정: 발화요인과 인명피해 발생 여부의 연관성 분석
- Kruskal–Wallis 검정: 발화요인별 재산피해 분포 차이 분석
- Cramér's V 및 Epsilon squared: 효과크기 평가

통계적으로 유의한 차이가 발견되더라도 인과관계를 의미하지 않으며, 표본 수와 효과크기를 함께 고려했습니다.

## 8. Streamlit 대시보드

5개 분석 탭을 구현했습니다.

1. 종합 현황
2. 재산피해 분석
3. 인명피해 분석
4. 통계 검정
5. 데이터 품질 및 전처리

발화요인과 표준화된 건물구조를 기준으로 데이터를 필터링할 수 있으며, 분석 결과를 그래프로 확인하고 필터링된 데이터를 CSV로 다운로드할 수 있습니다.

## 9. 프로젝트 실행

Python 가상환경 생성 후 `requirements.txt`에 정의된 패키지를 설치합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

원본 데이터를 `data/raw/`에 배치한 뒤 분석 파이프라인을 실행합니다.

```bash
python src/01_data_profile.py
python src/02_preprocessing.py
python src/03_clean_data.py
python src/04_fire_analysis.py
python src/05_damage_analysis.py
python src/06_casualty_building_analysis.py
python src/07_statistical_analysis.py
python src/08_building_risk_analysis.py
python src/09_preprocessing_validation.py
```

대시보드 실행:

```bash
streamlit run app.py
```

원본 데이터는 저장소에 포함하지 않습니다. 데이터 출처와 이용 조건을 확인하여 별도로 확보해야 합니다.

## 10. 분석의 한계

- 건물구조별 시설 수와 규모가 없어 화재 발생 위험률을 산출하지 않았습니다.
- 발화층의 괄호 표기는 공식 코드 정의 확인 전까지 잠정 분류로 취급합니다.
- 결측값은 무조건 제거하거나 0으로 대체하지 않았습니다.
- 통계적 연관성을 인과관계로 해석하지 않았습니다.
